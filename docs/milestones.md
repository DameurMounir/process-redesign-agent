# Milestone and branch contract

| Milestone | Branch | Exit decision |
|---|---|---|
| 01 | `01-case-and-evidence` | Is the baseline trusted and reproducible enough to analyze? |
| 02 | `02-analysis-models` | Are bottlenecks, rules, controls, and traceability modeled correctly? |
| 03 | `03-agent-design` | Are interpretation, calculation, and human authority separated? |
| 04 | `04-working-vertical` | Does one complete local comparison and selection journey work? |
| 05 | `05-evaluation` | Do public claims survive benchmark, adversarial, security, and package gates? |
| 06 | `06-public-case-study` | Can a visitor understand, reproduce, and challenge the result? |

Each branch is frozen at a validated head and merged through a documented pull
request. A failed gate narrows or repairs scope; it does not weaken the gate.
