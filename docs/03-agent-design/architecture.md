# Milestone 03 — controlled redesign agent design

The agent separates four authorities:

1. **Evidence analysis** measures the frozen AS-IS case and traces sources.
2. **Scenario engine** applies explicit transformation assumptions to three TO-BE options.
3. **Advisor** explains rankings but has no selection authority.
4. **Human reviewer** will make the actual future-process selection in Milestone 04.

The scenario engine rejects any option that drops a mandatory control. A soft 12-week / USD 180,000 pilot envelope affects the trade-off score but does not masquerade as a hard compliance rule.

The default weighted comparison is designed to answer the project question without hiding uncertainty: the top score is a candidate, not an approval, and every projected benefit is labeled as a synthetic deterministic scenario rather than a production forecast.
