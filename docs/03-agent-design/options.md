# Future-state options

| Option | Design posture | Main advantage | Main trade-off |
|---|---|---|---|
| OPT-A | controlled incremental | low effort and change risk | does not reach the target operating envelope |
| OPT-B | balanced parallel-control | combines queue reduction, control evidence, ownership, and feasible pilot scope | moderate implementation effort and change risk |
| OPT-C | automation-first | strongest modeled operating performance | exceeds the 12-week / USD 180k soft pilot envelope and carries the highest change risk |

All three preserve C-01 through C-05, including named human approval for high-risk activation.
