
# Security policy

## Supported scope

This repository is an independent public portfolio case study. It uses fictional
business evidence only, performs no production automation, and writes only to
explicit local output paths.

## Report a concern

Do not open a public issue containing credentials, private customer material, or
a working exploit. Use GitHub's private security-advisory workflow for the
repository owner.

## Public-boundary rules

- Never commit API keys, tokens, private keys, `.env` files, databases, model
  caches, or copied production data.
- Never replace the synthetic AtlasBridge case with disguised real-company
  evidence.
- Model output is advisory. It cannot approve a process option or authorize an
  external effect.
- Missing baseline data must block quantified benefit claims.
